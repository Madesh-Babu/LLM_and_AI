				Git Commands & Its Purposes

1. sudo apt-get install git                 ---> git insatllation.

2. git config --global user.name "[Name]"   ---> it config our name while commits.

3. git config --global user.email "[email]" ---> it config our email while commits.

4. git config --list                        ---> We check our info like name,email, etc...

5. git status                               ---> check status like modified,staged,etc...

Once we added a file using 'git add [file_name]' its staged.

6. git restore --staged [file_name]         ---> It does unstaged what you previous staged one.

7. git branch -m [old_name] [new_name]      ---> rename master branch to main 

8. git push -u origin main                  ---> push the branch name after creating new branch then only we use push and pull for that branch

9. git branch -d [branch_name]              ---> delete a branch

10. git reset --hard HEAD                   ---> after using revert if we want to remove exclametry mark on near file name. like (un-revert)

11. git rm --cached [file_name]             ---> it delete in only repo not in local file

12. git pull origin [branch_name]           ---> it pull repo files in our local machine.

13. git reset --hard HEAD~1                 ---> uncommit the pushed commit.

14. git remote add origin [https or ssh]    ---> connecting to our local machine

15. git branch [new_branch_name]            ---> creating new branch

16. git reset [file_name]                   ---> its undo what we add before commit.

17. git push origin --delete [branch_name]  ---> Delete the branch in the repo not in local machine.

18. git branch -d [branch_name]             ---> delete the specific branch in local machine but we must to switch the another branch and then delete the branch then only its works.
